# Student_performance_analysis
my first repository based on student analysis project 
Case Study Title

Student Performance Analysis Using Google Sheets

2. Problem Statement

Educational institutions maintain student records containing attendance percentages, marks and department details. Analysing these records manually can be time-consuming and may make it difficult to identify students with poor academic performance. This case study focuses on using Google Sheets to organize, analyse and visualize student data. It helps identify top performers, compare department-wise results and find students who require academic support.

3. Objectives

To organize student records in a spreadsheet.

To calculate total and average marks.

To identify the highest and lowest marks.

To analyse student attendance percentages.

To sort and filter student records.

To compare department-wise academic performance.

To create charts and visualizations.

To identify students who need academic support.

4. Dataset Description

The dataset consists of 12 students from four different departments: AIDS, CSE, IT and ECE.

The dataset contains the following fields:

Field

Description

Student ID

Unique identification number of each student

Name

Name of the student

Department

Department of the student

Attendance %

Percentage of attendance

Marks

Marks obtained by the student

The dataset is used to analyse academic performance and attendance patterns.

5. Spreadsheet Functions Used

The following Google Sheets functions were used:

Function

Purpose

SUM()

Calculates total marks

AVERAGE()

Calculates average marks

MAX()

Finds the highest marks

MIN()

Finds the lowest marks

COUNT()

Counts the total number of students

IF()

Identifies Pass or Fail

COUNTIF()

Counts students based on department

SUMIF()

Calculates department-wise total marks

AVERAGEIF()

Calculates department-wise average marks

Additional formulas were used to identify students with attendance below 75%.

6. Data Analysis Techniques Performed

The following data analysis techniques were performed:

Sorting: Students were arranged in descending order according to their marks.

Filtering: Students scoring above 80 marks were identified.

Grouping: Students were grouped according to their departments.

Conditional Formatting: Marks above 85 were highlighted in green, and attendance below 75% was highlighted in red.

Department-wise Summary: Total marks, average marks and student counts were calculated for each department.

Performance Analysis: Students with low marks and attendance were identified for additional academic support.

7. Charts and Visualizations Created

The following charts and visualizations were created using Google Sheets:

Bar Chart: Displays department-wise average marks.

Pie Chart: Shows the percentage distribution of students across departments.

Histogram: Represents the distribution of student marks.

Heat Map: Uses conditional formatting to highlight student performance levels.

These visualizations make the comparison and interpretation of student data easier.

9. Conclusion

The Student Performance Analysis case study demonstrates how Google Sheets can be used effectively to organize, analyse and visualize student academic data. By applying spreadsheet functions, sorting, filtering, conditional formatting and charts, student performance and attendance patterns can be understood easily. The analysis identifies the IT department as the highest-performing department and highlights students who require additional academic support. Overall, this study shows how spreadsheet tools help simplify data analysis and support better academic decision-making.
